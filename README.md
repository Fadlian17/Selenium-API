# Selenium-API

Framework automation berbasis **Selenium + Pytest** untuk pembelajaran dan testing automation dengan berbagai tingkat kompleksitas.

---

## 📁 Struktur Project

### 🟢 **SeleniumDriverDasar/**
**Tujuan**: Pembelajaran dasar Selenium WebDriver
- Script-script sederhana untuk memahami konsep dasar Selenium
- Implementasi API Selenium dasar
- Screenshot dan laporan HTML sederhana

### 🟡 **SeleniumMedium/**
**Tujuan**: Framework automation testing tingkat menengah dengan fitur lengkap
- Framework untuk end-to-end testing website automationteststore.com
- **Fitur**:
  - ✅ Automation register user ke website
  - ✅ Random data generator untuk email & username
  - ✅ Logger otomatis ke file log
  - ✅ Screenshot otomatis untuk success & failed test
  - ✅ HTML report lengkap dengan embedded screenshot
  - ✅ Struktur project clean & modular

### 🔴 **SeleniumHigh/**
**Tujuan**: Framework testing automation tingkat tinggi yang modular
- Framework untuk testing website dan API dengan arsitektur advanced
- **Fitur**:
  - **Selenium WebDriver**: Testing UI otomatis
  - **API Testing**: Testing API dengan requests
  - **Page Object Model**: Struktur modular dan mudah maintain
  - **Pytest**: Framework testing yang powerful
  - **HTML Reports**: Laporan test yang informatif

---

## 🎯 Progressive Learning Path

1. **SeleniumDriverDasar** → Belajar konsep dasar Selenium
2. **SeleniumMedium** → Framework lengkap dengan fitur enterprise
3. **SeleniumHigh** → Framework advanced dengan arsitektur modular dan API testing

---

## 🚀 Quick Start

### SeleniumDriverDasar
```bash
cd SeleniumDriverDasar
python dasar-selenium.py
```

### SeleniumMedium
```bash
cd SeleniumMedium
pip install -r requirements.txt
pytest tests/ -v
```

### SeleniumHigh
```bash
cd SeleniumHigh
pip install -r requirements.txt
pytest tests/ -v
```
